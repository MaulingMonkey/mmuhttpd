MaulingMonkey's Micro (µ) HyperText Transfer Protocol Daemon

Usage:
    mmuhttpd [flags] some/dir

Options:
    some/dir                    Optional.  Files in this directory will be served.  Defaults to the CWD.
    --allow-all-ipv4            Allow non-localhost traffic (bind to any/all IPv4 addresses)
    --allow-all-ipv6            Allow non-localhost traffic (bind to any/all IPv6 addresses)
    --help                      Print this usage information
    --[no-]open                 [Don't] open a browser to the listening address after starting
    --port [port]               Listen on port [port] instead of on a port between 9001 ..= 9999
